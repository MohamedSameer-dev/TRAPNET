⚠️ 4. ESP32 Pin Safety & Boot Strapping Restrictions

When designing and assembling ESP32 circuits, specific GPIO pins exhibit hardware restrictions during the power-on boot sequence. Misconfiguring these pins can prevent the microcontroller from booting.

GPIO Pin Boot Strapping Behavior Hardware Restriction / Configuration Rule
GPIO0 Boot Mode Select Must be HIGH during power-up for normal execution. Driven LOW for flashing mode.
GPIO2 Onboard LED / Boot State Must be left floating or pulled LOW during boot. Connected to blue onboard LED.
GPIO12 (MTDI) Flash Voltage Select Must be LOW at boot. Pulling HIGH sets internal flash voltage to 1.8V instead of 3.3V, causing boot crash.
GPIO15 (MTDO) SDIO Slave Select Must be HIGH at boot. Used for Panic Button with internal pull-up enabled.
GPIO34, 35, 36, 39 Input Only Pins Cannot be used as outputs! Have no internal pull-up/pull-down resistors. Require external 10kΩ pull-down for vibration sensing.
