1.3 Wire-by-Wire Connection Guide

Follow these connections in order. Complete one module at a time. Power OFF the ESP32 while wiring.

Connection A: LD2410C mmWave Radar → ESP32

Connection B: SIM800L GSM Module → ESP32

1.4 Common Ground Rule

ALL GND pins from ALL modules MUST connect to the same GND bus. This includes: ESP32 GND, all sensors, relay module, SIM800L, GPS, OLED, SD card, Raspberry Pi, 12V adapter, LM2596 converters, and battery pack. A single disconnected ground will cause random resets, communication failures, and erratic behavior.

2.2 LM2596 Buck Converter Setup

You have TWO LM2596 converters. Each must be individually calibrated with a multimeter BEFORE connecting any module.

1
Connect 12V adapter output to LM2596 INPUT terminals (IN+ and IN-).

Don't connect anything to the output yet.

2
Plug in the 12V adapter to mains. Measure LM2596 OUTPUT with a multimeter.

Set multimeter to DC voltage, probes on OUT+ and OUT-.

3
Turn the potentiometer screw (tiny brass screw on the blue potentiometer) SLOWLY.

Clockwise = lower voltage. Counter-clockwise = higher voltage. Adjust until multimeter reads:

  • LM2596 #1: 5.00V (±0.05V) — for ESP32 VIN
  • LM2596 #2: 4.00V (±0.05V) — for SIM800L
4
Apply a drop of nail polish or hot glue on the potentiometer screw to prevent accidental rotation from vibration.
If LM2596 #2 outputs above 4.4V, the SIM800L will be permanently damaged. If below 3.4V, it will fail to register on the cellular network. Always verify with a multimeter first.

18650 Cell #1 (3.7V) 18650 Cell #2 (3.7V) ┌──────────┐ ┌──────────┐ │ (+) ────┼──── wire ────┼── (-) │ ← SERIES connection = 7.4V │ (-) │ │ (+) ────┼──┐ └──────┬───┘ └──────────┘ │ │ │ ▼ ▼ ┌──────────────────────────────────────────┐ │ TP4056 Charging Module │ │ │ │ B+ ← 7.4V from batteries │ │ B- ← Battery negative │ │ OUT+ → To LM2596 #1 IN+ (through │ │ Schottky diode OR relay for │ │ auto-switchover) │ │ OUT- → To LM2596 #1 IN- │ │ │ │ USB Micro → Charging input (5V 1A) │ └──────────────────────────────────────────┘
The TP4056 is designed for single-cell 3.7V charging. For 2× series cells (7.4V), you need a 2S BMS (Battery Management System) board instead of TP4056. The TP4056 option works if you use cells in parallel (3.7V, double capacity). For simplicity in your prototype, use 2× 18650 in parallel with TP4056 → this gives 3.7V × 5200mAh, then feed into LM2596 #1 which boosts/bucks to 5V.

2.5 Battery Life Estimate

With 2× 18650 in parallel (5200mAh at 3.7V) powering only the ESP32 + sensors (without RPi and solenoid):

  • Standby mode: ~350mA draw → 5200/350 = ~14.8 hours
  • Active alert mode: ~650mA draw → 5200/650 = ~8 hours
  • Realistic estimate (mixed): 4–6 hours (accounts for WiFi TX bursts and GSM peaks)

void loop() {
  unsigned long now = millis();

  // 1. Read Radar
  if (now - lastRadarRead > 100) {  // Every 100ms
    readRadar();
    lastRadarRead = now;
  }

  // 2. Read IR Sensors
  irDoorTriggered   = (digitalRead(IR_DOOR)   == LOW);
  irWindowTriggered = (digitalRead(IR_WINDOW)  == LOW);

  // 3. Process Vibration (sliding window)
  if (now - vibWindowStart > VIB_WINDOW_MS) {
    int totalPulses = vibPulseCount1 + vibPulseCount2;
    vibrationDetected = (totalPulses > VIB_PULSE_THRESHOLD);
    vibPulseCount1 = 0;
    vibPulseCount2 = 0;
    vibWindowStart = now;
  }

  // 4. Read GPS (if available)
  readGPS();

  // 5. Read RPi Serial (YOLO results)
  readRPiSerial();

  // 6. Check Panic Button
  if (panicPressed) {
    panicPressed = false;
    Serial.println("[PANIC] Button pressed! Triggering full lockdown.");
    triggerLockdown("PANIC_BUTTON");
  }

  // 7. === MULTI-SENSOR FUSION LOGIC ===
  if (systemState == ARMED) {
    evaluateThreat();
  }

  // 8. Update OLED every 500ms
  if (now - lastOledUpdate > 500) {
    updateStatusOLED();
    lastOledUpdate = now;
  }

  delay(10);  // Small yield
}

// ═══════════════════ SENSOR FUSION ═══════════════════
void evaluateThreat() {
  int threatScore = 0;
  String triggerSource = "";

  // Radar: human detected with sufficient energy
  if (radarHumanDetected && radarStatEnergy > RADAR_ENERGY_THRESHOLD) {
    threatScore += 3;
    triggerSource += "RADAR ";
  }

  // IR beam broken (door or window opened)
  if (irDoorTriggered) {
    threatScore += 2;
    triggerSource += "IR_DOOR ";
  }
  if (irWindowTriggered) {
    threatScore += 2;
    triggerSource += "IR_WINDOW ";
  }

  // Vibration detected (potential forced entry)
  if (vibrationDetected) {
    threatScore += 2;
    triggerSource += "VIBRATION ";
  }

  // RPi YOLO person confirmation
  if (rpiPersonConfirmed) {
    threatScore += 3;
    triggerSource += "YOLO_PERSON ";
  }

  /*
   * Threat Level Decision Matrix:
   * Score >= 5: CONFIRMED INTRUSION → Full lockdown
   * Score >= 3: HIGH ALERT → Pre-alert (log + notify, no lock yet)
   * Score < 3:  NORMAL → Continue monitoring
   *
   * Examples:
   *   Radar + IR Door = 3+2 = 5 → LOCKDOWN
   *   Radar + Vibration = 3+2 = 5 → LOCKDOWN
   *   IR Door alone = 2 → Monitor (could be wind)
   *   Radar alone = 3 → Pre-alert (could be pet)
   *   YOLO + Radar = 3+3 = 6 → LOCKDOWN (highest confidence)
   */

  if (threatScore >= 5) {
    unsigned long now = millis();
    if (now - lastLockdownTime > LOCKDOWN_COOLDOWN_MS) {
      Serial.printf("[FUSION] THREAT CONFIRMED! Score: %d | Sources: %s\n",
                     threatScore, triggerSource.c_str());
      triggerLockdown(triggerSource);
      lastLockdownTime = now;
    }
  } else if (threatScore >= 3) {
    Serial.printf("[FUSION] High alert. Score: %d | Sources: %s\n",
                   threatScore, triggerSource.c_str());
    logToSD("HIGH_ALERT", triggerSource);
  }
}

// ═══════════════════ LD2410C RADAR READER ═══════════════════
void readRadar() {
  // LD2410C sends frames at ~10Hz on UART2
  // Frame format: Header(4) + DataType(2) + TargetState(1) + ...
  // We look for the simple engineering mode data

  static uint8_t buf[64];
  static int bufIdx = 0;

  while (radarSerial.available()) {
    uint8_t b = radarSerial.read();
    buf[bufIdx++] = b;

    // Look for frame header: F4 F3 F2 F1
    if (bufIdx >= 4 &&
        buf[bufIdx-4] == 0xF4 && buf[bufIdx-3] == 0xF3 &&
        buf[bufIdx-2] == 0xF2 && buf[bufIdx-1] == 0xF1) {
      // End of frame detected, parse previous data
      if (bufIdx > 12) {
        parseRadarFrame(buf, bufIdx - 4);
      }
      bufIdx = 0;
    }

    if (bufIdx >= 64) bufIdx = 0;  // Buffer overflow protection
  }
}

void parseRadarFrame(uint8_t* data, int len) {
  // Simple target data parsing
  // Byte 6: Target state (0=none, 1=moving, 2=stationary, 3=both)
  // Byte 7-8: Moving distance (cm, little-endian)
  // Byte 9: Moving energy (0-100)
  // Byte 10-11: Static distance (cm, little-endian)
  // Byte 12: Static energy (0-100)

  if (len < 13) return;

  // Find data header F4F3F2F1 ... look for target data after AA header
  for (int i = 0; i < len - 8; i++) {
    if (data[i] == 0xAA) {  // Target data marker
      uint8_t state = data[i + 1];
      int movDist   = data[i + 2] | (data[i + 3] << 8);
      int movEnergy = data[i + 4];
      int staDist   = data[i + 5] | (data[i + 6] << 8);
      int staEnergy = data[i + 7];

      radarMoving     = (state == 1 || state == 3);
      radarStationary = (state == 2 || state == 3);
      radarHumanDetected = (state != 0);
      radarMovEnergy  = movEnergy;
      radarStatEnergy = staEnergy;
      radarDistance   = staDist / 100.0;  // Convert cm to meters

      return;
    }
  }
}

int buildBeaconFrame(uint8_t* packet, const char* ssid, uint8_t channel) {
  // 802.11 Beacon Frame structure
  int ssidLen = strlen(ssid);
  int idx = 0;

  // Frame Control (Beacon)
  packet[idx++] = 0x80; packet[idx++] = 0x00;
  // Duration
  packet[idx++] = 0x00; packet[idx++] = 0x00;
  // Destination: broadcast
  for (int i = 0; i < 6; i++) packet[idx++] = 0xFF;
  // Source: random MAC
  packet[idx++] = 0xDE; packet[idx++] = 0xAD;
  packet[idx++] = 0xBE; packet[idx++] = 0xEF;
  packet[idx++] = 0x00; packet[idx++] = channel;
  // BSSID: same as source
  packet[idx++] = 0xDE; packet[idx++] = 0xAD;
  packet[idx++] = 0xBE; packet[idx++] = 0xEF;
  packet[idx++] = 0x00; packet[idx++] = channel;
  // Sequence
  packet[idx++] = 0x00; packet[idx++] = 0x00;
  // Timestamp (8 bytes)
  for (int i = 0; i < 8; i++) packet[idx++] = 0x00;
  // Beacon interval
  packet[idx++] = 0x64; packet[idx++] = 0x00;
  // Capability info
  packet[idx++] = 0x31; packet[idx++] = 0x04;
  // SSID tag
  packet[idx++] = 0x00;           // Tag: SSID
  packet[idx++] = (uint8_t)ssidLen; // Length
  memcpy(&packet[idx], ssid, ssidLen);
  idx += ssidLen;
  // Supported rates
  packet[idx++] = 0x01; packet[idx++] = 0x08;
  packet[idx++] = 0x82; packet[idx++] = 0x84;
  packet[idx++] = 0x8B; packet[idx++] = 0x96;
  packet[idx++] = 0x0C; packet[idx++] = 0x12;
  packet[idx++] = 0x18; packet[idx++] = 0x24;
  // Channel
  packet[idx++] = 0x03; packet[idx++] = 0x01;
  packet[idx++] = channel;

  return idx;
}

typedef struct {
  char type[16];       // "SOS_ALERT"
  char source[16];     // Node ID
  float lat;
  float lng;
  int radarEnergy;
  uint8_t hopCount;
} TrapnetAlert;

void onESPNowRecv(const uint8_t *mac, const uint8_t *data, int len) {
  if (len == sizeof(TrapnetAlert)) {
    TrapnetAlert alert;
    memcpy(&alert, data, sizeof(alert));

    // Relay to next hop if hop count < 3
    if (alert.hopCount < 3) {
      alert.hopCount++;
      esp_now_send(NULL, (uint8_t*)&alert, sizeof(alert));
      Serial.printf("[ESP-NOW] Relayed alert from %s (hop %d)\n",
                     alert.source, alert.hopCount);
    }
  }
}

# ═══════════════════ SERIAL COMMUNICATION ═══════════════════
class ESP32Link:
    """Handles bidirectional serial communication with ESP32."""

    def __init__(self, port, baud):
        try:
            self.ser = serial.Serial(port, baud, timeout=0.1)
            log.info(f"Serial connected: {port} @ {baud}")
        except serial.SerialException as e:
            log.error(f"Serial connection failed: {e}")
            self.ser = None

    def send(self, person_detected, confidence, tamper_detected):
        """Send detection result to ESP32 as JSON."""
        if self.ser is None:
            return

        msg = {
            "person": person_detected,
            "confidence": round(confidence, 2),
            "tamper": tamper_detected,
            "timestamp": int(time.time())
        }
        try:
            line = json.dumps(msg) + "\n"
            self.ser.write(line.encode())
            log.debug(f"Sent to ESP32: {msg}")
        except Exception as e:
            log.error(f"Serial write error: {e}")

    def read(self):
        """Read messages from ESP32 (lockdown events, etc.)"""
        if self.ser is None or not self.ser.in_waiting:
            return None
        try:
            line = self.ser.readline().decode().strip()
            if line:
                return json.loads(line)
        except (json.JSONDecodeError, UnicodeDecodeError):
            pass
        return None


# ═══════════════════ TAMPER DETECTION ═══════════════════
class TamperDetector:
    """Detects camera sabotage: spray paint, cloth cover, physical smash."""

    def __init__(self):
        self.baseline_brightness = None
        self.frame_count = 0

    def check(self, frame):
        """Returns True if camera tampering is detected."""
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        mean_brightness = np.mean(gray)
        std_brightness = np.std(gray)

        # Establish baseline from first 30 frames
        if self.frame_count < 30:
            if self.baseline_brightness is None:
                self.baseline_brightness = mean_brightness
            else:
                self.baseline_brightness = (self.baseline_brightness * 0.9 +
                                            mean_brightness * 0.1)
            self.frame_count += 1
            return False

        # Check 1: Sudden darkness (spray paint, cloth, hand over lens)
        if mean_brightness < TAMPER_BRIGHTNESS_THRESHOLD:
            log.warning(f"TAMPER: Darkness detected! Brightness={mean_brightness:.1f}")
            return True

        # Check 2: Uniform frame (cloth/tape over lens — no texture)
        if std_brightness < TAMPER_UNIFORMITY_THRESHOLD:
            log.warning(f"TAMPER: Uniform frame! StdDev={std_brightness:.1f}")
            return True

        # Check 3: Sudden massive brightness change (>80% drop from baseline)
        if self.baseline_brightness > 30:
            drop = (self.baseline_brightness - mean_brightness) / self.baseline_brightness
            if drop > 0.80:
                log.warning(f"TAMPER: Brightness drop {drop*100:.0f}%!")
                return True

        # Update rolling baseline slowly
        self.baseline_brightness = self.baseline_brightness * 0.99 + mean_brightness * 0.01
        return False


# ═══════════════════ PERSON DETECTOR ═══════════════════
class PersonDetector:
    """YOLOv8 nano person detection optimized for RPi Zero 2W."""

    def __init__(self, model_path):
        if YOLO_AVAILABLE:
            log.info(f"Loading YOLO model: {model_path}")
            self.model = YOLO(model_path)
            # Warm-up inference
            dummy = np.zeros((320, 320, 3), dtype=np.uint8)
            self.model.predict(dummy, verbose=False, conf=CONFIDENCE_THRESHOLD)
            log.info("YOLO model loaded and warmed up")
        else:
            self.model = None
            log.warning("YOLO not available — using fallback motion detection")

    def detect(self, frame):
        """Returns (person_found: bool, confidence: float, annotated_frame)"""
        if self.model is None:
            return False, 0.0, frame

        # Resize for faster inference on RPi Zero 2W
        small = cv2.resize(frame, (320, 320))

        results = self.model.predict(
            small,
            verbose=False,
            conf=CONFIDENCE_THRESHOLD,
            classes=[0]  # Class 0 = "person" in COCO dataset
        )

        person_found = False
        max_confidence = 0.0

        for r in results:
            if r.boxes is not None and len(r.boxes) > 0:
                for box in r.boxes:
                    conf = float(box.conf[0])
                    if conf > max_confidence:
                        max_confidence = conf
                        person_found = True

                    # Draw bounding box on original frame
                    x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
                    # Scale coordinates back to original frame size
                    h, w = frame.shape[:2]
                    x1 = int(x1 * w / 320)
                    y1 = int(y1 * h / 320)
                    x2 = int(x2 * w / 320)
                    y2 = int(y2 * h / 320)
                    cv2.rectangle(frame, (x1, y1), (x2, y2), (0, 0, 255), 2)
                    cv2.putText(frame, f"Person {conf:.0%}",
                                (x1, y1 - 10), cv2.FONT_HERSHEY_SIMPLEX,
                                0.6, (0, 0, 255), 2)

        return person_found, max_confidence, frame

def save_snapshot(frame, event_type):
    """Save timestamped snapshot to SD card."""
    os.makedirs(SNAPSHOT_DIR, exist_ok=True)
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

    cv2.imwrite(filename, frame, [cv2.IMWRITE_JPEG_QUALITY, 85])

# ═══════════════════ MAIN LOOP ═══════════════════
def main():
    log.info("═══════════════════════════════════════")
    log.info("  TRAPNET Vision Module — Starting...")
    log.info("═══════════════════════════════════════")

    # Initialize components
    esp32 = ESP32Link(SERIAL_PORT, SERIAL_BAUD)
    tamper = TamperDetector()
    detector = PersonDetector(YOLO_MODEL)

    # Open camera
    log.info(f"Connecting to camera: {CAMERA_URL}")
    cap = cv2.VideoCapture(CAMERA_URL)

    if not cap.isOpened():
        log.error("Failed to open camera! Check URL or connection.")
        # Notify ESP32 that camera is down
        esp32.send(False, 0.0, True)
        return

    log.info("Camera connected. Starting detection loop...")

    frame_counter = 0
    last_person_time = 0

    try:
        while True:
            ret, frame = cap.read()
            if not ret:
                log.warning("Frame capture failed. Reconnecting...")
                cap.release()
                time.sleep(2)
                cap = cv2.VideoCapture(CAMERA_URL)
                continue

            frame_counter += 1

            # Process every Nth frame to save CPU
            if frame_counter % FRAME_SKIP != 0:
                continue

            # 1. Check for camera tamper
            is_tampered = tamper.check(frame)
            if is_tampered:
                esp32.send(False, 0.0, True)
                save_snapshot(frame, "TAMPER")
                time.sleep(1)
                continue

            # 2. Run person detection
            person_found, confidence, annotated = detector.detect(frame)

            if person_found:
                log.info(f"PERSON DETECTED! Confidence: {confidence:.0%}")
                save_snapshot(annotated, "PERSON")
                last_person_time = time.time()

            # 3. Send result to ESP32
            esp32.send(person_found, confidence, False)

            # 4. Check for messages from ESP32
            esp32_msg = esp32.read()
            if esp32_msg:
                event = esp32_msg.get("event", "")
                if event == "LOCKDOWN":
                    log.warning("ESP32 reports LOCKDOWN — saving burst snapshots")
                    for i in range(5):
                        ret, burst_frame = cap.read()
                        if ret:
                            save_snapshot(burst_frame, f"LOCKDOWN_{i}")
                        time.sleep(0.5)

            time.sleep(0.1)

    except KeyboardInterrupt:
        log.info("Shutting down...")
    finally:
        cap.release()
        log.info("Camera released. Goodbye.")


if __name__ == "__main__":
    main()

6 Physical Response Mechanisms

6.1 Solenoid Door Lock — Fail-Secure Design

PropertyValue
Operating Voltage12V DC
Current Draw350–500mA when energized
Hold Force60kg (sufficient for standard doors)
Lock ModeFail-Secure — Power ON = LOCKED, Power OFF = UNLOCKED
Activation Time< 100ms (near-instant)
Fail-Secure means the door automatically unlocks if power is lost (battery dies). This is a safety feature — in case of fire or emergency, the occupant can always escape. The solenoid lock is additionally secured by the system keeping the relay energized via battery backup.

6.2 Relay Switching — Active-LOW Logic

The 2-channel relay module uses optocoupler isolation and active-LOW triggering:

  • GPIO32 = HIGH → Relay OFF → Solenoid de-energized → Door UNLOCKED
  • GPIO32 = LOW → Relay ON → Solenoid energized → Door LOCKED

This is why in the firmware, we initialize digitalWrite(RELAY_LOCK, HIGH) — to start in the unlocked (disarmed) state.

6.3 1N4007 Flyback Diode — Why It's Critical

The solenoid lock contains a wire coil (inductor). When current through an inductor is suddenly switched OFF, the collapsing magnetic field generates a reverse voltage spike that can reach 50–200V. This spike travels backward through the relay contacts and can destroy the relay, the ESP32, or other components.

The 1N4007 diode is placed across the solenoid terminals in reverse bias:

Normal operation (relay ON): 12V+ ──→ Solenoid Coil ──→ GND Current flows normally. Diode is reverse-biased (blocks). Relay turns OFF (spike): Solenoid generates -50V spike ──→ Diode becomes forward-biased ──→ Absorbs spike as heat ↓ Spike safely dissipated. ESP32 and relay survive.

6.4 Fog Machine Integration

  • What: Mini 12V fog/smoke machine connected to Relay Channel 2
  • How: GPIO33 = LOW energizes relay CH2 → powers fog machine for 5 seconds
  • Effect: Room fills with dense, non-toxic glycol-based fog in <10 seconds, reducing visibility to <1 metre
  • Purpose: Disorientation — intruder cannot see to steal or find exit, buying time for police arrival
  • Safety: Fog is non-toxic (same as stage/party fog). Dissipates naturally in 15–30 minutes

6.5 Safety Override Mechanisms

An authorized person accidentally trapped inside can escape via:

  1. SMS Disarm: Send a pre-configured passcode via SMS to the SIM800L number → ESP32 reads it → disarms system and unlocks door
  2. Physical Key: Mechanical override lock on the inside of the door (separate from solenoid)
  3. Power Disconnect: In worst case, disconnecting the battery pack de-energizes the solenoid → door unlocks (fail-secure design)

2
Turn ON fans and AC. Monitor again for 5 minutes with nobody in the room.

Record the new maximum "Static Energy". This is your environmental noise ceiling.

3
Stand in the room motionless for 2 minutes. Record "Static Energy" values.

This is your human signature level. Should be 50–80+.

4
Set RADAR_ENERGY_THRESHOLD to a value between your environmental noise ceiling and human signature level.

ESP-NOW not relaying Alerts don't reach other nodes WiFi channel mismatch between nodes All nodes must be on same WiFi channel. Set channel=1 in ESP-NOW config.
Relay clicks but solenoid doesn't lock Click sound but no magnetic pull 12V not reaching solenoid, or wiring on NO instead of NC Check 12V supply to relay COM terminal. Verify wires are on NO (Normally Open) terminal.
RPi camera connection drops OpenCV VideoCapture returns False RTSP stream timeout, network change, or camera sleep mode Auto-reconnect logic in Python (already in trapnet_vision.py). Disable camera sleep mode.

10.3 Quick Diagnostic Checklist

When something isn't working, go through this checklist in order:

  1. ✅ Is the common GND connected between ALL modules?
  2. ✅ Is the correct voltage reaching each module? (Measure with multimeter)
  3. ✅ Are TX/RX wires crossed correctly? (TX→RX, RX→TX)
  4. ✅ Is the baud rate matching on both sides of each serial connection?
  5. ✅ Are input-only GPIOs (34, 35, 36, 39) used correctly with external pull-downs?
  6. ✅ Is the SIM card inserted with correct orientation (gold contacts down)?
  7. ✅ Is the SD card formatted as FAT32 (not exFAT)?
  8. ✅ Is the 1000µF capacitor polarity correct? (Longer lead = positive)
  9. ✅ Is the 1N4007 diode direction correct? (Stripe toward positive terminal)
  10. ✅ Open Serial Monitor at 115200 baud — what's the error message?
