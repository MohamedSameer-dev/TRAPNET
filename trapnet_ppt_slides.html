LAYER 1 — DETECT

Sensor Layer

  • LD2410C 24GHz mmWave radar for human presence detection
  • IR sensors (×2) on door & window for entry breach detection
  • SW-420 vibration sensors (×2) for forced-entry vibration
  • NEO-6M GPS module for location tracking of trapped victim
  • CCTV Camera (RPi CSI) for visual confirmation via AI
UART Digital GPIO SoftSerial
LAYER 2 — PROCESS

Processing Layer

  • ESP32-S3 DevKit as central coordinator — sensor fusion + SOS
  • Raspberry Pi Zero 2W runs OpenCV + YOLOv8 for object detection
  • Multi-sensor data fusion to reduce false alarms
  • Dual buck converters (5V + 4V) for stable multi-rail power
  • 18650 Li-Ion battery backup (4–6 hours via TP4056)
UART ×3 I2C SPI WiFi BLE
LAYER 3 — RESPOND

Response Layer

  • 12V electromagnetic solenoid lock for automatic door locking
  • 2-channel relay module (opto-isolated) for safe high-voltage switching
  • MicroSD card module (16GB) for local evidence logging
  • 0.96" OLED display (SSD1306) for real-time system status
  • All responses trigger within <500ms of confirmed intrusion
Relay Control VSPI I2C
LAYER 4 — ALERT (SOS)

SOS Alert Layer

  • WiFi Beacon SSID broadcast (15–30m radius) — no app needed
  • BLE Eddystone beacon (10–15m radius) — passive detection
  • GSM SMS via SIM800L — sends alert to predefined contacts
  • ESP-NOW mesh relay (200m+) — device-to-device, no router
  • Multi-channel redundancy ensures alert even if one path fails
WiFi BLE GSM ESP-NOW

WHY THIS METHODOLOGY?

🔁
Layered Separation
Each layer is independent — can be tested, debugged, and upgraded individually
📡
Multi-Channel SOS
4 alert paths (WiFi, BLE, GSM, ESP-NOW) ensure message gets through
🔋
Power Resilience
Dual-rail power + battery backup = works during power outages
🧠
AI + Sensor Fusion
YOLOv8 + multi-sensor fusion reduces false positives to near zero

Slide 3 — Justification of Methodology

JUSTIFICATION OF METHODOLOGY

TRAPNET
Why the Four-Layer Pipeline Architecture is the Optimal Approach
1

Modular & Testable Design

  • ▸Each layer operates independently — a sensor failure doesn't crash the alert system
  • ▸Individual layers can be unit-tested before system integration
  • ▸New sensors or alert channels can be added without redesigning the whole system
2

Multi-Sensor Fusion Accuracy

  • ▸Single-sensor systems have high false-positive rates (wind, pets, shadows)
  • ▸Fusing radar + IR + vibration + camera reduces false alarms to near-zero
  • ▸YOLOv8 on RPi provides AI-level visual confirmation before triggering response
3

Redundant Alert Channels

  • ▸GSM SMS works even without internet — guaranteed message delivery
  • ▸WiFi + BLE beacons alert nearby devices passively — no app install needed
  • ▸ESP-NOW mesh provides device-to-device relay over 200m without WiFi router
4

Real-World Resilience

  • ▸Dual-rail power (5V + 4V) prevents SIM800L 2A spikes from browning out ESP32
  • ▸18650 battery backup ensures 4–6 hours of operation during power failure
  • ▸MicroSD evidence logging works offline — no cloud dependency
